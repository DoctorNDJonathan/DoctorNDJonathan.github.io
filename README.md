## How to update (all from github.com, no software needed)
1. Open the file on GitHub → click the pencil icon (Edit).
2. Find the section by its comment, e.g. `<!-- PUBLICATIONS -->`.
3. Copy an existing `<li>…</li>` line, paste it at the top, and change the text.
4. Click **Commit changes**. The site updates in about a minute.

**Add a publication:** copy a `<li>` in the right group in `index.html`.
**Add an achievement:** add a `<li>` at the top of "News & milestones".
**Add teaching material:** upload the file into `teaching/` (Add file → Upload files), then link it in `teaching/index.html`.
